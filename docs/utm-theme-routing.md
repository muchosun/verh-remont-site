# Переключение темы по UTM-параметрам

## Как работает сайт

По умолчанию сайт открывается в светлой теме. Тема определяется до загрузки страницы, поэтому посетитель не видит промежуточного переключения.

Приоритет выбора:

1. Явный параметр `theme=light` или `theme=dark`.
2. Слова, найденные в UTM и поисковых параметрах.
3. Ручной выбор пользователя, сделанный переключателем в шапке в рамках текущего посещения.
4. Светлая тема по умолчанию.

## Какие параметры анализируются

- `utm_campaign`
- `utm_content`
- `utm_term`
- `keyword`
- `query`
- `search`
- `segment`
- `intent`

Регистр букв значения не имеет.

## Тёмная тема

Включается, если в перечисленных параметрах найдено одно из значений:

- `люкс`
- `премиум` или часть слова `преми`
- `элитный` или часть слова `элит`
- `дизайнерский` или часть слова `дизайнерск`
- `бизнес-класс`
- `vip`
- `lux`
- `premium`

Пример:

`https://verhremont.ru/?utm_source=yandex&utm_campaign=remont_lux&utm_term=ремонт+квартиры+премиум`

## Светлая тема

Включается, если в параметрах найдено одно из значений:

- `эконом`
- `бюджет`
- `стандарт`
- `обычный` или часть слова `обычн`
- `косметический` или часть слова `космет`
- `недорогой` или часть слова `недорог`
- `econom`
- `budget`
- `standard`

Пример:

`https://verhremont.ru/?utm_source=yandex&utm_campaign=remont_econom&utm_term=недорогой+ремонт+квартиры`

## Принудительное управление

- Светлая тема: `https://verhremont.ru/?theme=light`
- Тёмная тема: `https://verhremont.ru/?theme=dark`

Параметр `theme` имеет приоритет над UTM. Его удобно использовать для проверки рекламных объявлений и согласования посадочной страницы.

## Что можно изменить после обратной связи маркетолога

- набор ключевых слов для каждой темы;
- параметры, из которых считывается поисковый запрос;
- тему по умолчанию;
- приоритет ручного выбора относительно UTM;
- отдельные правила для конкретных кампаний или групп объявлений.
