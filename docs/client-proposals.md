# Клиентские коммерческие предложения

Раздел `/client/` публикуется на существующем GitHub Pages вместе с сайтом.
Каждое КП доступно публично по отдельной ссылке, без входа в аккаунт.
Общий каталог предложений на главной странице раздела не выводится.

Единый стиль: `client/assets/proposal.css`, галерея: `proposal.js`.
Шаблон: `tools/client-proposals/proposal.html`. Используется Onest с сайта.
HTML адаптируется к телефону и десктопу; референсы открываются целиком,
галерея работает с клавиатуры, печать оформлена на одну страницу A3.
К готовому предложению можно приложить PDF для скачивания.

Создание следующего КП из проверенных данных:

```sh
python3 tools/create-client-proposal.py --data /path/proposal.json --assets-dir /path/originals --pdf /path/approved.pdf
```

Формат JSON показан в `proposal.json` существующего КП. Этот шаблон рассчитан
на 6 референсов и 8 пунктов работ. Площадь, ставка и общая стоимость обязательны;
генератор проверяет их согласованность. Оригиналы копируются без изменения.
Уникальный адрес генерируется автоматически. Существующие КП не перезаписываются.
Команда создаёт только файлы: проверка и публикация выполняются отдельно.
Не добавлять в публичные данные личные сведения, которые не предназначены для публикации.
